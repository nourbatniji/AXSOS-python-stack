# Python Backend Development — Course Projects

A collection of assignments and projects from a full-stack Python backend course. Each folder represents a chapter, progressing from Python fundamentals through production-ready Django apps.

---

## Chapters

### 01 · OOP (Object-Oriented Programming)
Core OOP concepts in Python — classes, inheritance, and encapsulation.
- `BankAccount` — account management with class methods
- `Users-BankAccount` — users linked to bank accounts
- `user` — User class with attributes and behaviors
- `zoo` — Zoo and animal class hierarchy
- `LinkList` — custom linked list implementation

### 02 · Linked Lists
Standalone linked list exercises covering insertion, deletion, and traversal operations.

### 03 · MySQL
Relational database design and querying.
- ERD design and normalization
- Sakila & World sample databases
- SQL query exercises

### 04 · Flask
Intro to Python web development with Flask.
- Routing, templates, and Jinja2
- Form handling and sessions
- Projects: Counter, Dojo Survey, Ninja Gold, Great Number Game, Checkerboard, Fruit Store

### 05 · Django
Full Django curriculum across multiple sub-chapters:

| Folder | Topic |
|---|---|
| `01_fundamentals` | URLs, views, templates, sessions |
| `02_orm` | Django ORM, models, relationships |
| `03_fullstack` | Full-stack Django apps with auth |
| `04_study_sync` | Capstone — study session tracker with Pomodoro timer |
| `05_dojo_ninjas` | Dojo Ninjas CRUD app |
| `06_exam` | Course exam project |
| `07_code_quest` | CodeQuest assignment app |

---

## Tech Stack

- **Language:** Python 3
- **Frameworks:** Flask, Django
- **Database:** MySQL, SQLite (via Django ORM)
- **Tools:** Git, virtualenv
